# Visualization and Analysis of Car Sales Using Microsoft Excel
----

### This repository features a data analysis project focused on car sales, utilizing pivot tables in Microsoft Excel and was developed during my studies in the IBM Data Analyst Professional Certificate course.
----

## Introduction
  The project involves the creation of an interactive dashboard to visualize and analyze sales trends. It provides insights into sales performance, making it easier to interpret key metrics and support data-driven decision-making. The dashboard enables dynamic exploration of the data through various filters and views. This project is part of a hands-on lab from the course Data Visualization and Dashboards with Excel and Cognos, which is part of the IBM Data Analyst Professional Certificate, available at: [https://www.coursera.org/professional-certificates/ibm-data-analyst].
